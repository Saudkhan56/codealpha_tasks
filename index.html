About Project

Crafted with Pure Web Standards

Visual Gallery is an interactive web showcase built using HTML5, CSS3 Grid & Flexbox, and Vanilla JavaScript. It demonstrates clean code practices, responsive layout techniques, dark/light theme persistence, real-time search, sorting, favorite management, dynamic image & category creation, and keyboard-accessible modal overlays.

  • ⚡ Pure Vanilla JavaScript (No frameworks)
  • 🌙 Dark / Light Mode with LocalStorage
  • 🔍 Real-Time Search & Custom Sorting
  • ❤️ Favorites & Custom Category Support
  • ➕ Add & Delete Image Functionality
